# 教师组织考试操作说明（MVP）

## 前置账号

教师账号由管理员在 Django Admin 中创建或授权教师角色，并从独立的教师管理后台域名登录；教师入口不开放自助注册。教师需要先创建班级，学生才能在独立的学生问诊域名注册时选择班级。本地测试默认使用 `http://localhost:5174/` 作为教师端，使用 `http://localhost:5173/` 作为学生端。

## 1. 班级管理

进入“班级管理”：

1. 填写全局唯一的班级编号和班级名称，直接创建班级。
2. 学生在注册页面选择有效班级，注册成功后自动进入班级名单，教师无需逐个添加。
3. 班级列表显示班级编号和学生人数；点击“管理学生”可查看姓名和邮箱。
4. 教师可将学生移出班级，或转入自己管理的另一个有效班级。这些操作只影响以后发布的任务，已经发布的任务保存独立名单快照，不会改变。
5. 班级列表同时显示正常和已冻结班级。教师可冻结正常班级或重新激活已冻结班级；冻结后不能用于新注册、转班目标或发布新任务，但不会删除已有学生关系、历史任务、答卷和名单记录。

## 2. 病例版本

在“病例库”纵向浏览并编辑全部内容卡片，然后完成发布。患者开场白、至少一个患者事实和口腔体格检查文字所见是发布必填项；体格检查图片与附件可选。问诊任务只能选择包含体格检查资料的最新已发布不可变版本，修改草稿不会改变已发布任务所使用的病例内容。

学生在交卷前可随时用自然语言申请检查。首次触发后，患者回复同意，对话中生成“口腔体格检查所见”记录，并自动带入病例的“专科检查”；学生在交卷前和交卷记录中都可重复打开。未触发的学生在教师发布反馈后也可以查看标准检查资料。

## 3. 发布任务

进入“问诊任务”并填写：

- 任务名称。
- 已发布病例版本。
- 至少有一名学生的班级。
- 整场作答限时，范围为 1–240 分钟。
- 开放时间和最晚截止时间。

学生实际截止时间取“开始时间加整场限时”和“任务最晚截止时间”中的较早者。浏览器倒计时只负责显示，服务端截止时间是最终依据。

学生作答采用单阶段流程：问诊对话和病例编辑在最终交卷前始终同时开放。主诉、现病史、既往史、家族史、诊断、处理和医嘱会自动保存；提交后生成一份只读病例记录，不能继续提问或修改。

## 4. 结束任务与反馈

任务页面显示任务人数、未开始、作答中、已交卷和已超时人数。

- “结束任务”会立即停止仍在进行的作答，并把这些会话标记为超时。
- 任务未结束时不能发布反馈。
- “发布反馈”后，学生才能看到标准诊断和标准检查。
- 学生完成或超时后，系统生成可追溯的规则评分。教师可在“查看学生答卷”中检查完整对话、结构化病例记录、分项得分、证据和标准答案。
- 教师评价项在尚未赋分时显示为“待评价”，不计入当前得分。
- 学生交卷或超时后，教师可在答卷中逐项填写复核分和改分理由，并填写总体评语。每次保存都会新增审计版本，不覆盖历史复核。
- 统一发布反馈后复核结果冻结；学生只会看到允许公开的评分项、复核理由和教师评语。
- 答卷列表顶部按当前问诊任务统计完成率、平均得分率、平均当前得分、平均用时、高频遗漏和常见错误。
- “导出 CSV”包含任务名单快照中的所有学生，包括未开始学生；具体字段和口径见 [教学统计与导出标准](./teacher-reporting.md)。
