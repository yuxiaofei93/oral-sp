# 教师组织考试操作说明（MVP）

## 前置账号

学生必须先在 `/student/` 学生入口用手机号完成注册。教师账号由管理员在 Django Admin 中创建或授权教师角色，并从 `/teacher/` 教师入口登录；教师入口不开放自助注册。

## 1. 课程与学生

进入教师工作区的“课程与学生”：

1. 创建课程，课程编号只能使用大写字母、数字、`_` 和 `-`。
2. 在课程下创建班级。
3. 选择班级，在名单框中粘贴学生手机号。支持换行、空格、中英文逗号或分号分隔，每批最多 100 个号码。
4. 如果任一号码未注册、格式错误或不是学生账号，整批不会导入。修正后重新提交即可。

从班级移出学生只影响以后发布的任务。已经发布的任务保存独立名单快照，不会随班级名单变化。

## 2. 病例版本

在“病例库”完成七步编辑并发布。考试任务只能选择已发布的不可变病例版本；修改草稿不会改变已发布任务所使用的病例内容。

## 3. 发布任务

进入“考试任务”并填写：

- 任务名称。
- 已发布病例版本。
- 至少有一名学生的班级。
- 整场作答限时，范围为 1–240 分钟。
- 开放时间和最晚截止时间。

学生实际截止时间取“开始时间加整场限时”和“任务最晚截止时间”中的较早者。浏览器倒计时只负责显示，服务端截止时间是最终依据。

## 4. 收卷与反馈

任务页面显示任务人数、未开始、作答中、已交卷和已超时人数。

- “统一收卷”会立即停止仍在进行的作答，并把这些会话标记为超时。
- 任务未收卷时不能发布反馈。
- “发布反馈”后，学生才能看到标准诊断和标准检查。
- 学生完成或超时后，系统生成可追溯的规则评分。教师可在“查看学生答卷”中检查完整对话、阶段提交、分项得分、证据和标准答案。
- AI 辅助评价和教师评价项在尚未赋分时显示为“待评价”，不计入当前得分。
- 对含 AI 评分项的已结束答卷，教师可显式调用 DeepSeek。页面显示实际模型版本、耗时、token 数、逐项分数、置信度、证据、理由和建议；教师确认需要重跑时会新增一版结果。
- AI 评价不发送学生姓名或手机号，学生作答被视为不可信数据；模型引用不存在的消息/提交、返回越界分数或缺少评分项时，整次结果不会写入成绩。
- 学生交卷或超时后，教师可在答卷中逐项填写复核分和改分理由，并填写总体评语。每次保存都会新增审计版本，不覆盖历史复核。
- 仍有 AI 评价运行时不能发布反馈。统一发布反馈后 AI 评价和复核结果都冻结；学生只会看到允许公开的评分项、AI 建议、复核理由和教师评语。
- 答卷列表顶部按当前考试任务统计完成率、平均得分率、平均当前得分、平均用时、高频遗漏和常见错误。
- “导出 CSV”包含任务名单快照中的所有学生，包括未开始学生；具体字段和口径见 [教学统计与导出标准](./teacher-reporting.md)。
