# 教学统计与导出标准（MVP）

## 统计范围

统计以单个考试任务为范围，因此病例版本、班级和任务开放时间天然固定。任务发布后使用名单快照，后来加入或移出班级的学生不会改变历史任务统计。

当前指标包括：

- 完成率：已完整交卷人数除以任务名单人数；超时学生单独统计，不计为完整交卷。
- 平均当前得分：所有已生成评分学生的最新有效分数平均值。
- 平均得分率：逐名学生计算“当前得分 / 总满分”后取平均，便于未来不同评分标准之间比较。
- 平均用时：已交卷或已超时学生从开始到结束的平均秒数。
- 高频遗漏、常见错误：按当前仍未解决的评分反馈项聚合；教师复核为满分后，该项不再计入遗漏或错误。

作答中的学生不进入平均分和平均用时，页面会继续单独显示其当前状态。

## CSV 字段

CSV 包含任务名单中的全部学生，并按学生姓名和手机号排序：

- 学生姓名、手机号和作答状态。
- 开始时间、结束时间和用时秒数。
- 自动得分、教师复核后的当前得分、已评分满分和总满分。
- 是否仍有待评价项、遗漏项和错误项。
- 最新教师复核版本及教师评语。

文件使用 UTF-8 BOM，方便常见中文表格软件直接识别。任何以 `=、+、-、@` 开头的文本都会增加安全前缀，防止表格软件把学生姓名、手机号或评语解释为公式。

统计和导出接口沿用任务创建教师的访问范围；管理员可访问全部任务，其他教师和学生不能越权访问。
