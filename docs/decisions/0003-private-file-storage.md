# ADR 0003：MVP 私有文件存储

- 状态：已接受
- 日期：2026-08-04

## 决策

MVP 使用服务器本地私有目录保存病例附件，不运行 MinIO，也不把附件放进 Git。数据库只保存文件标识、相对对象键、类型、大小、哈希和脱敏状态。

浏览器不能直接访问媒体目录。学生下载或查看资料时，必须经过 Django 权限、会话阶段和检查申请规则校验，再由受控接口返回文件。

## 体格检查媒体实现

- 口腔体格检查图片只接受 JPEG、PNG、WebP。服务端验证真实图片格式、纠正 EXIF 方向并重新编码，以清除图片元数据。
- 其它附件不限制扩展名，但单文件上限为 10 MB；服务端统一以 `application/octet-stream` 和 `Content-Disposition: attachment` 返回，禁止浏览器内联执行。
- 原始文件名仅作为下载展示名称，磁盘对象键使用随机名称；所有内容接口均校验教师病例权限或学生本人会话权限。
- 学生只有在主动触发体格检查后才能在作答期间读取媒体；未触发者要等教师统一发布反馈。
- 发布版本复用不可变文件对象并复制版本关联。草稿移除文件时，只在没有任何版本继续引用该对象后删除磁盘内容。
- 第一版不提供病毒扫描。系统依赖受信任教师上传，并要求教师逐次确认资料已获授权且完成脱敏。

## S3 是什么

S3 是对象存储接口标准。它通常用于保存图片、PDF、音频等非结构化文件；PostgreSQL 保存文件记录和业务关系，对象存储保存实际二进制内容。将来可以把本地存储适配器替换成学校的 S3 兼容服务，而不改变病例和会话表。

## 测试病例图片

原始 Windows 目录中的 4 张图片仅为测试数据，不复制进项目。病例媒体资料为可选项，必须经过授权和脱敏后才能导入。
