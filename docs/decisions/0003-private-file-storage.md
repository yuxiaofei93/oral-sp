# ADR 0003：MVP 私有文件存储

- 状态：已接受
- 日期：2026-08-04

## 决策

MVP 使用服务器本地私有目录保存病例附件，不运行 MinIO，也不把附件放进 Git。数据库只保存文件标识、相对对象键、类型、大小、哈希和脱敏状态。

浏览器不能直接访问媒体目录。学生下载或查看资料时，必须经过 Django 权限、会话阶段和检查申请规则校验，再由受控接口返回文件。

## S3 是什么

S3 是对象存储接口标准。它通常用于保存图片、PDF、音频等非结构化文件；PostgreSQL 保存文件记录和业务关系，对象存储保存实际二进制内容。将来可以把本地存储适配器替换成学校的 S3 兼容服务，而不改变病例和会话表。

## 测试病例图片

原始 Windows 目录中的 4 张图片仅为测试数据，不复制进项目。后续病例以文字为主，媒体资料为可选项，必须经过授权和脱敏后才能导入。
