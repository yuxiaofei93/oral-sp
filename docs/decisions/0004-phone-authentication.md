# ADR 0004：手机号账号认证

- 状态：已接受
- 日期：2026-08-04

## 决策

MVP 使用手机号和密码注册登录。中国大陆 11 位手机号统一保存为 E.164 格式，例如 `13800138000` 保存为 `+8613800138000`。

- 自助注册用户默认获得学生角色。
- 教师和管理员由管理员在后台创建或授权。
- 使用服务端 Session Cookie，不把长期身份令牌保存到浏览器本地存储。
- 注册、登录和退出写请求必须通过 CSRF 校验。
- 注册和登录接口执行基础限流。

## 暂不实现

短信验证码依赖短信供应商、签名模板、费用和防刷策略，MVP 暂不接入。模型和接口保留 `phone_verified_at` 字段，后续可增加短信验证而不更换账号主键。
