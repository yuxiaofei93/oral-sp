# ADR 0005：患者模型网关与安全回退

- 状态：已接受
- 日期：2026-08-04

## 决策

MVP 在 Django 单体内提供供应商无关的患者模型网关：

- `mock` 用于本地开发和自动测试，不访问外部服务。
- `openai_compatible` 调用外部 `/chat/completions` API。
- 外部模型配置只通过服务端环境变量注入。
- 每次调用只提供学生当前问题和本地规则命中的患者事实。
- 标准诊断、检查的教师解读、评分规则不会进入患者提示上下文。

## 输出约束与回退

外部模型必须返回患者回答和实际使用的事实编码。服务端校验事实编码是否属于本次允许集合，并检查回答是否泄露病例诊断。校验失败时不把原回答发给学生，而是使用已录入的患者口语表达组成确定性回答。

外部模型不可用时，本次学生问题仍会以不可变消息保存，并标记回答生成失败。客户端使用同一个消息编号重试，服务端不会重复创建问题。

## 审计边界

数据库记录供应商、模型、提示版本、请求内容哈希、命中事实编码、耗时、token 数和错误码。学生问题和患者回答属于考试记录；密钥和额外拼接的完整提示词不写入数据库或日志。
