# ADR 0005：患者模型网关与安全回退

- 状态：已接受
- 日期：2026-08-04

## 决策

MVP 在 Django 单体内提供供应商无关的患者模型网关：

- `mock` 用于本地开发和自动测试，不访问外部服务。
- `deepseek` 默认调用 `https://api.deepseek.com/chat/completions`，当前模型为 `deepseek-v4-flash`。
- `openai_compatible` 调用外部 `/chat/completions` API。
- 外部模型配置只通过服务端环境变量注入。
- 语义路由调用接收当前问题、本次问诊全部学生与患者历史消息和所有允许披露的患者事实，只返回相关事实编码。
- 患者回答调用只接收语义路由选中的事实。
- 标准诊断、检查的教师解读、评分规则不会进入患者提示上下文。

语义路由直接依据事实内容理解同义改写、时间问法和结合整场历史对话的省略问法，不要求教师另外维护提示词或典型问法。路由和患者回答调用关闭思考，并要求 JSON object 输出。模型空输出或无效 JSON 最多重试一次。系统不使用大模型评价学生或生成分数。

## 输出约束与回退

外部模型必须返回患者回答和实际使用的事实编码。患者事实是语义依据而不是台词，模型需要去掉病历书写口吻，以第一人称日常短句重新表达。服务端校验事实编码是否属于本次允许集合，并检查回答是否泄露病例诊断或照抄病历式事实。检测到照抄时先纠正一次；仍不合格或其他校验失败时，不把原回答发给学生，而是使用受控的口语化规则组成确定性回答。

外部模型不可用时，本次学生问题仍会以不可变消息保存，并标记回答生成失败。客户端使用同一个消息编号重试，服务端不会重复创建问题。

## 审计边界

语义路由和患者回答分别记录供应商、模型、提示版本、请求内容哈希、命中事实编码、耗时、token 数和错误码。学生问题和患者回答属于考试记录；密钥和额外拼接的完整提示词不写入数据库或日志。
