# ADR 0004：邮箱账号与验证码认证

- 状态：已接受
- 日期：2026-08-07

## 决策

MVP 使用规范化后的邮箱作为唯一登录标识，并使用服务端 Session Cookie：

- 学生注册前必须获取并提交六位邮箱验证码，同时选择有效班级。
- 教师和管理员由管理员创建或授权，不开放教师自助注册。
- 学生、教师和管理员均可通过邮箱验证码重置密码。
- 注册、登录、验证码和密码重置写请求必须通过 CSRF 校验。
- 登录与验证码接口分别限流；同一邮箱的验证码 60 秒内不能重复发送。
- 验证码有效期 10 分钟、最多尝试 5 次、成功使用后立即失效。
- 数据库只保存基于服务端密钥计算的验证码摘要，不保存验证码明文。
- 忘记密码的验证码请求使用统一响应，避免直接暴露邮箱是否已经注册。

## 邮件发送

本地开发使用 Django console email backend，邮件内容输出在 API 终端。部署测试服务时通过环境变量切换为 SMTP；邮件供应商和发件域名不进入代码。

## 数据迁移

系统尚未上线，旧手机号账号和测试数据不迁移。应用邮箱账号迁移前清空本地开发数据库，再创建新的管理员账号、课程和班级。
