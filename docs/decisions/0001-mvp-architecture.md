# ADR 0001：MVP 技术架构

- 状态：已接受
- 日期：2026-08-04

## 决策

采用前后端分离、同源部署的模块化单体：

- React、TypeScript 和 Vite 构建浏览器端。
- Django 5.2 LTS 和 Django REST Framework 提供 API、认证、领域规则和管理能力。
- PostgreSQL 保存结构化业务数据。
- Nginx 提供静态前端并反向代理 `/api/`。
- 外部模型只能通过内部 LLM Gateway 访问。

## 低资源约束

目标 MVP 主机可能只有 1 核 1 GB：

- API 默认一个 worker。
- PostgreSQL 最大连接数 30，使用保守的内存参数。
- 不部署本地大模型、MinIO、Redis 或 Celery。
- 前端构建为静态文件，由 Nginx 提供。
- 耗时模型调用不得持有数据库事务。

SQLite 适合单机演示，但不作为课堂部署数据库。学生集中提交消息和阶段答案时会产生并发写入，PostgreSQL 的并发和约束更符合系统需求。

## 模块边界

后端按领域拆分为身份、教学组织、病例、问诊会话、评分、模型网关和审计模块。模块共用一个数据库和部署单元，第一阶段不拆微服务。
