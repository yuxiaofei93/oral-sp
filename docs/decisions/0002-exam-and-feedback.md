# ADR 0002：考试、作答和反馈规则

- 状态：已接受
- 日期：2026-08-04

## 已确认规则

- 每名学生对同一个病例任务只允许一次正式尝试。
- 学生在最终交卷前可以继续发送追问，并同步编辑病例记录。
- 已发送消息不可编辑或删除，服务端永久保留原始顺序。
- 病例草稿自动保存，最终只提交一次；交卷后问诊消息与病例记录均不可修改。
- 每个病例任务使用整场考试计时；具体时间由教师配置，浏览器倒计时仅用于显示，服务端截止时间是最终依据。
- MVP 不设置病例发布审核和教师改分的二次审核。
- 教师关闭考试后统一释放反馈，未关闭前学生不能获得标准答案。
- 反馈可以包含遗漏项、错误项、标准答案、标准诊断、标准检查、分数和 AI 评语。
- 病例、会话和评分记录按六个月保留进行数据模型设计。

## 反馈释放

任务包含 `feedback_released_at`。只有教师显式结束任务后才能发布反馈；结束任务时仍在进行的会话统一标记为超时，因此发布反馈时所有作答都已完成或已超时。学生反馈 API 必须检查任务已经发布反馈。

这样不会因为某名学生缺席而永久阻塞教学进度；教师可以确认后手动结束任务。
