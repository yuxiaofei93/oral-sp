# ADR 0002：考试、作答和反馈规则

- 状态：已接受
- 日期：2026-08-04

## 已确认规则

- 每名学生对同一个病例任务只允许一次正式尝试。
- 学生在问诊阶段可以继续发送追问。
- 已发送消息不可编辑或删除，服务端永久保留原始顺序。
- 结束问诊或提交某个阶段后，该阶段内容不可返回修改。
- 每个病例任务支持考试计时；具体时间由教师配置。
- MVP 不设置病例发布审核和教师改分的二次审核。
- 教师关闭考试后统一释放反馈，未关闭前学生不能获得标准答案。
- 反馈可以包含遗漏项、错误项、标准答案、标准诊断、标准检查、分数和 AI 评语。
- 病例、会话和评分记录按六个月保留进行数据模型设计。

## 反馈释放

任务包含 `feedback_released_at`。只有教师显式结束并发布反馈后，该时间才会写入。学生反馈 API 必须同时检查会话已完成和任务已经发布反馈。

这样不会因为某名学生缺席而永久阻塞课程；教师可以在确认收卷后手动关闭考试。
