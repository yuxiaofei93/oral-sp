# ADR 0005：只保留班级，不设置课程层级

- 状态：已接受
- 日期：2026-08-07

## 决策

MVP 不设置课程实体。教师直接创建和管理班级，学生注册时直接选择班级，问诊任务直接关联班级。

- 班级编号全局唯一，用于在注册和任务发布时清楚区分班级。
- 普通教师只能查看和管理自己创建的班级，管理员可以管理全部班级。
- 班级停用采用可恢复的安全冻结，不影响已经发布的任务、名单快照和历史答卷。
- 旧课程下的班级在迁移时继承课程创建教师；旧数据出现重复班级编号时自动追加序号。

## 理由

MVP 的教学规模较小，课程层级没有提供足够价值，反而增加教师创建班级、学生选班和任务发布时的操作成本。保留班级即可满足组织学生、生成任务名单快照和限制教师管理范围的需求。
