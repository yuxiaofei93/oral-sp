# 可解释评分配置标准（MVP）

## 评分原则

MVP 采用“确定性规则评分、教师最终复核”的方式。患者模型不评价学生，也不生成分数；系统不会因为配置不完整而生成虚假分数。

每个自动评分项保存：

- 评分编码、维度、满分和自动得分。
- 已完成、部分完成、未完成或待评价状态。
- 命中的学生消息 ID 或病例记录 ID。
- 对话/答案证据摘录、判定理由和标准答案。
- 评分规则版本。

会话结束或超时后生成不可覆盖的评分快照。学生只有在教师统一发布反馈后才能看到设置为“学生可见”的评分项。

## 显式评分项

教师在“评分规则”中选择评价方式和规则依据。

### 问诊事实点

- 规则依据：`问诊事实点`
- 配置一个或多个患者事实编码。
- 按命中的事实数量比例评分。
- 证据同时包含学生问题和患者回答；患者模型失败、问题尚未获得回答或会话结束后返回的回答不计分。

### 诊断名称

- 规则依据：`诊断名称`
- 可配置一个或多个标准诊断名称。
- 系统在病例记录的“诊断”中匹配标准名称及病例中配置的同义词。
- 现有初步诊断与最终诊断规则暂时统一读取该字段；留空配置时仍按评分项维度选择需要匹配的标准诊断。

### 检查项目

- 规则依据：`检查项目`
- 可配置一个或多个检查编码。
- 系统在病例记录的“处理”中匹配检查名称或编码，并按命中比例评分。
- 留空时匹配病例中所有要求学生主动申请的检查。

### 体格检查申请

- 规则依据：`体格检查申请`
- 学生在最终交卷前通过自然语言主动触发口腔体格检查即得满分，未触发记为遗漏。
- 证据包含学生申请、患者同意和系统生成的体格检查记录消息。
- 该评分项按病例需要手动添加，不会因为病例配置了体格检查而自动计分。

### 病例字段关键词（兼容现有配置）

- 规则依据：`阶段答案关键词`
- 教师配置界面暂时保留原有四个选项，服务端映射到同一份病例记录：病史摘要读取主诉、现病史、既往史和家族史，初步判断读取诊断，检查计划读取处理，最终判断读取诊断、处理和医嘱。
- 配置可接受关键词。
- “按命中比例评分”根据命中数量计分；“命中任一即满分”适用于多个等价表达。

关键词规则只适合明确、低争议的内容。复杂推理质量不得仅凭关键词自动给分。

## 教师评价与待评价项

评价方式为“教师评价”的项目保持“待评价”，不计入当前得分，直到教师复核赋分。已有病例中的旧 `ai` 评价配置在迁移时统一转换为教师评价。

页面同时显示：

- 当前自动得分。
- 当前可自动评分的满分。
- 包含待评价项的总满分。

这样不会把尚未完成的教师评价误报为零分，也不会让学生误以为规则得分已经是最终总分。

教师端显示全部评分项及完整总分。学生端只汇总设置为“学生可见”的评分项；隐藏项不会影响学生看到的得分、满分或“是否仍有待评价项”状态。

## 教师复核

学生交卷或超时后，教师可以对自动评分和待评价项填写复核分。复核分必须在 0 到该项满分之间；任何逐项调整都必须填写理由。

- 自动评分证据保持不可变，复核分作为独立版本叠加，不覆盖原始结果。
- 每次保存记录复核教师、时间、逐项分数、理由和总体评语。
- 未在新版本中再次提交的既有调整会被保留，避免无理由地恢复自动分。
- 当前得分优先使用最新教师复核分；没有复核分时使用规则自动分。
- “待评价”项经教师赋分后计入当前得分和已评分满分。
- 教师统一发布反馈后，所有复核分和评语冻结。
- 学生仍然只能看到设置为“学生可见”的评分项及对应复核理由。
