# DeepSeek 接入说明

## 使用范围

MVP 使用同一个 `deepseek-v4-flash` 模型完成两类患者扮演工作：

- 患者语义路由：关闭思考，根据当前问题、本次问诊全部学生与患者历史消息和允许披露的患者事实返回相关事实编码。
- 患者回答：关闭思考，只能使用语义路由选中的患者事实作答，并把病历式事实改写成患者现场会说的自然口语。

DeepSeek 不接收学生评分标准、标准诊断或答卷，不评价学生，也不生成分数。评分仅由确定性规则和教师复核完成。

体格检查后的患者主动询问不调用 DeepSeek。服务端直接按已发布病例中的问题快照逐项发送，学生回答仅写入会话记录；主动问答完成后才恢复普通患者模型问诊。

患者回答提示分为三层：服务端维护且教师不可编辑的固定患者策略、教师可编辑的患者表达风格，以及每轮生成的结构化运行数据。固定策略是唯一的 system 消息，规定事实边界、安全要求、提示注入防护和 JSON 输出格式；表达风格只控制语气、情绪、配合程度和回答习惯，并作为不可信数据随完整历史、当前问题和已授权事实一起传入，不能覆盖固定策略。

## 服务端配置

复制示例环境文件后，只在本机或服务器的 `.env` 中填写密钥：

```dotenv
LLM_PROVIDER=deepseek
LLM_BASE_URL=https://api.deepseek.com
LLM_API_KEY=sk-替换为真实密钥
LLM_MODEL=deepseek-v4-flash
LLM_TIMEOUT_SECONDS=30
```

`.env` 已被 Git 忽略。真实密钥不得出现在前端变量、病例内容、日志、截图、提交记录或聊天消息中。更换配置后重启 API 服务。

## 输入与持久化边界

患者语义路由发送当前问题、本次会话内按时间顺序排列的全部学生与患者历史消息，以及所有允许披露的患者事实。患者回答发送当前问题、同一份完整历史、患者表达风格和路由选中的事实。事实的内部确定程度在模型输入中转换成中文的记忆状态，不向教师暴露实现变量名。系统消息、体格检查结果、标准诊断、标准检查解释、评分答案和用户身份不进入患者模型上下文。

系统不发送学生姓名、邮箱、班级或教师身份。数据库只持久化患者回答、命中事实编码和模型调用元数据，不持久化完整提示词或思维链；半年数据清理会随会话一并清理这些记录。

## 失败与重试

- 空内容或无效 JSON：同一请求最多受控重试一次。
- 患者回答照抄病历式事实：追加明确的口语化纠正后重试一次；仍照抄时不返回模型原文，改用受控规则回答并记录 `response_not_conversational`。
- 输出截断：标记失败，不采用不完整回答。
- 网络、限流或 DeepSeek 服务错误：返回明确错误码，学生可使用同一客户端消息编号稍后重试，不重复创建问题。

真实接口冒烟测试应使用不含真实学生个人信息的演示病例，并检查语义路由、患者回答、实际模型版本、耗时、token 数和安全回退。
