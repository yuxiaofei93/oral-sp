# 教师病例编辑标准（MVP）

教师通过七步表单编辑病例，不直接编写系统提示词。媒体资料是可选项，文字病例可以完整完成发布与问诊。

## 1. 教学设置

- 病例编号只使用大写字母、数字、`_` 和 `-`。
- 内部名称可以包含病种；学生名称不得泄露诊断。
- 设置专业方向、难度、适用年级、预计用时和考试限时。
- 教学目标描述学生在本病例中应训练的能力。

## 2. 患者身份

- 使用教学化名，不填写真实患者身份信息。
- 设置年龄、性别、职业、文化程度、性格、情绪和医学知识水平。
- 开场白是发布必填项，只表达主诉，不主动泄露完整病史或诊断。

## 3. 患者事实

每个事实是独立信息点，至少包含：

- 稳定且唯一的信息点编码。
- 分类、标准事实和患者口语表达。
- 能命中该事实的语义标签与同义说法。
- 主动披露、被问后披露或禁止披露。
- 患者对该事实的确定程度。
- 是否为必问项及对应分值。

模型不得自行补齐未录入事实。事实修改后需要重新发布版本，历史会话继续使用原发布版本。

## 4. 检查资料

- 检查名称和编码。
- 向学生释放的文字结果。
- 仅教师可见的标准解读。
- 释放阶段、是否要求主动申请及前置检查。
- 图片和附件后续通过私有文件接口添加，不是文字病例发布的前置条件。

## 5. 诊断规则

- 分开录入初步诊断、鉴别诊断和最终诊断。
- 配置可接受同义词、支持证据和反对证据。
- 该部分属于教师答案域，问诊阶段不进入患者模型上下文。

## 6. 评分规则

- 每个评分项有稳定编码、维度、名称、满分和评价方式。
- 规则评分用于可确定的信息点，AI 只辅助评价沟通和推理。
- 教师评价用于争议性或不能自动判断的内容。
- 发布后评分规则与病例事实一起形成不可变快照。

## 7. 预览与发布

发布前至少需要患者开场白和一个患者事实。正式教学病例建议达到产品验收标准中的 20 个事实点，并由教师自行完成医学内容审核。

每次发布生成递增版本号和内容哈希。重复发布完全相同的内容不会产生新版本；继续编辑草稿不会改变已发布版本。
